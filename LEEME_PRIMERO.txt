🚀 INICIO RÁPIDO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

1. Instalar dependencia:
   pip install PyMuPDF

2. Generar visualización:
   python3 generador_visualizacion_marker.py documento.pdf documento/ salida.html

3. Abrir en navegador:
   open salida.html

📊 PROCESAMIENTO POR LOTES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

./procesar_lote.sh

Esto procesará automáticamente todos los PDFs que tengan su directorio
de conversión de Marker y guardará las visualizaciones en visualizaciones/

💡 EJEMPLO COMPLETO
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

# 1. Convertir PDF con Marker
marker mi_documento.pdf --output_dir .

# 2. Generar visualización
python3 generador_visualizacion_marker.py \
  mi_documento.pdf \
  mi_documento \
  revision.html

# 3. Abrir en navegador
open revision.html

🐛 PROBLEMAS COMUNES
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

Error: ModuleNotFoundError: No module named 'fitz'
Solución: pip install PyMuPDF

Error: FileNotFoundError
Solución: Verifica que existan documento.pdf y documento/documento.md

Las imágenes no se ven
Solución: Abre el HTML desde el mismo directorio donde ejecutaste el script

Ver TUTORIAL_VISUALIZADOR_MARKER.md para más detalles.
